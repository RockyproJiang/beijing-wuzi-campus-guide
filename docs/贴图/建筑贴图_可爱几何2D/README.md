# 校园建筑 · 可爱几何 2D 贴图集

把 `C:\Users\rocky\Downloads\贴图\素材` 里 29 张建筑正面照片，转成了一套**纯 2D 平面贴图**。

- **没有任何 3D 建模**，也没有打开任何 3D 软件
- 每张图**全部由几何图形**绘制（圆角矩形、椭圆、多边形），不含照片像素
- 横向**无缝**：左右边缘严格衔接，绕建筑一圈重复也看不出接缝
- 尺寸 **2048 × 2048 px**，PNG，可直接当材质贴到任意平面上

## 怎么用

### 平铺到建筑立面
直接当材质用，UV 横向重复即可。因为左右无缝，`wrap / repeat` 模式下不会出现接缝。

### 绕一圈
一张图代表建筑的一个立面。四面相似的建筑（绝大多数校园楼都是这样），四个面用同一张图重复即可 —— 见 `01_用法示意_环绕四面.png`。

### 门口位置
每张图底部的门位于固定横向位置（默认 1～3 个），如果实际门不在那个位置，可以在引擎里用 UV 偏移把门转到正确朝向。

### 石牌坊（23 号）
它不是一个"面"，而是一个独立画面：石构门楼 + 匾额 + 拱形门洞，门洞里画了远处校园（楼、树、地面透视），所以看起来是能穿过去的。建议单独贴在一整块平面上，不要重复平铺。

## 关于"可爱"

在还原真实配色和层数的基础上，做了这些处理：

- 所有窗户都是**大圆角**，窗框有内凹阴影和窗台投影
- 玻璃上有斜向高光条，看起来是亮亮的、有反光
- 住宅类加了**窗台花箱**（小花是几何圆点拼的）
- 01 号保留并强化了**波浪阳台**，这是它最可爱的特征
- 底部有绿植盆栽、门口有雨棚、墙面有落水管和砖缝
- 整体是柔和扁平插画风，明度偏低饱和，不刺眼

## 技术说明

- 全部用 Python + Pillow 以几何图元绘制，4 倍超采样后缩到 2048，边缘干净
- 横向无缝通过「在 -W / 0 / +W 三个位置各画一遍，且随机状态复位」实现
- 竖肋、壁柱、橙条、波浪阳台都做了周期性吸附到画布宽度，保证首尾严格吻合
- 29 张全部通过接缝检测（接缝处色差 ≈ 0）
- 生成脚本在 `..\_gen\`（`gen2.py` 主渲染、`specs2.py` 参数表、`gate.py` 牌坊）
